YOUR PORTFOLIO PHOTO FOLDER

Add your own photos here before publishing:

1. Save your main portrait as: profile.jpg
   Location: public/images/profile.jpg
   This appears in the homepage hero section.

2. Optional: save another photo as: about.jpg
   Location: public/images/about.jpg
   This appears in the About section.

Recommended:
- JPG or WebP
- Main portrait: vertical 4:5 ratio, at least 900px tall
- About photo: landscape 16:9 ratio
- Use clear, well-lit photos with a simple background.

The website already contains empty photo frames. Until you add the files,
it displays a neat placeholder. No code changes are needed if you use
these exact filenames.

Do not upload private or sensitive photos.
